# Machine Learning Notebook

This website displays a project I worked on during my time at the Summer Institute of Biostatistics and Data Science under the guidance of Dr. Catalina Cañizares. 
In this project, we explore various statistical and machine learning models using the Youth Risk Behavior Survey (YRBS) 2023 dataset. 
Through this, I display different implementations and modeling techniques using the tidymodels framework in R.
