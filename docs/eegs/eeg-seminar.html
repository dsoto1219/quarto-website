Setting Up Data

Though they use the data at alexenge/erpcore, we will be downloading the data using the osfr package, as the erpcore R package seems to be broken.

pak::pak("osfr")

library(osfr)
library(here)    # For general handling of local data files

Moreover, we will only be using data from the N170 experiment, which showed that subjects who were hooked up to EEGs and were tasked with viewing faces elicited different responses than when they were tasked to view cars. We use the osfr package to get the data in BIDS format.

bids_dir <- here("eegs", "data/n170")
dir.create(bids_dir, recursive = TRUE)

# See the top-level folders

folders

# Get the folder with data in BIDS format
bids_folder <- folders[
  folders$name == "N170 Raw Data BIDS-Compatible",
]
bids_folder

bids_files <- osf_ls_files(
  bids_folder,
  n_max = Inf
)

osf_download(
  bids_files,
  path = bids_dir,
  conflicts = "overwrite",
  recurse = TRUE
)

Re-referencing

During recording (“online”), each electrode is measuring the difference in voltage compared to the reference electrode (e.g., FCz). In contrast, during preprocessing (“offline”), a new reference is typically chose:

  • Average reference: Difference to the average of all scalp channels
  • Linked mastoids: Difference to the average of the mastoid channels (M1 and M2)
eog_channels <- c("HEOG_left", "HEOG_right", "VEOG_lower")
dat_reref <- eeg_reference(dat_raw, ref_chans = "average", exclude = eog_channels)

Filtering

We now want to filter our signals for frequencies that represent brain waves, and nothing else. According to the seminar’s notes, the kinds of wave frequencies that we will encounter will represent the following EEG activity:

Frequency EEG activity
< 0.1 Hz Electrode drift, sweat artifacts
0.1–4 Hz (delta) Slow-wave sleep
4–8 Hz (theta) Drowsiness, idling
8–13 Hz (alpha) Relaxing, inhibition
13–30 Hz (beta) Active thinking, alertness
30–80 Hz (gamma) Binding, consciousness (?)
50 Hz (US: 60 Hz) Power line noise
> 80 Hz Muscle artifacts

Thus, we only really care about the waves with frequencies between 0.1 Hz and 30 Hz. To remove unwanted parts of the signal, we do the following:

  1. Convert time-domain EEG into the frequency domain via Fourier Transform
  2. Remove or attenuate certain frequencies, depending on whether they are in our range or not.
  • A high-pass filter will remove slow frequencies (in our case, <0.1 Hz)
  • A low-pass filter will remove fast frequencies (in our case, >30 Hz)
  • A band-pass filter combines a high-pass and low-pass filter
  • A band-stop filter removes a narrow frequency range (e.g. around 50 Hz)
  1. Convert cleaned signal back into the time domain

This can all be done with one function, eeg_filter:

dat_filt <- eeg_filter(dat_reref, low_freq = 0.1, high_freq = 30.0)
Band-pass FIR filter from 0.1 - 30 Hz
Transition bandwidth: 0.1 Hz
Filter order: 33792
Removing channel means...
plot_butterfly(dat_filt, time_lim, baseline = time_lim)

Extra: Downsampling

The sampling rate is the number of EEG voltages recorded per second (in Hz).

dat_raw$srate
[1] 1024

This means that each pair of samples is less than 1 ms apart:

1 / dat_raw$srate
[1] 0.0009765625

We don’t need that much temporal resolution, so we will downsample the data using eeg_downsample from the eegUtils library:

dat_downs <- eeg_downsample(dat_filt, q = 4.0) # q is the downsampling factor
Downsampling from 1024Hz to 256Hz.

This will reduce our computer’s memory load and make subsequent computations faster:

show_size_mb <- function(x) format(object.size(x), units = "MB")
lapply(list(before = dat_filt, after = dat_downs), show_size_mb)

Event Codes

Significant “events,” (e.g. stimuli, responses) are marked in the EEG recording by unique event codes. In this experiment, event codes between 1-40 mean the stimulus was a face, while event codes between 41-80 mean the stimulus was a car. Note that in my case, the task-N170_events.json file did not exist in the directory where the N170 data got downloaded, but that is ok because we still know from the paper that this convention was used. We can hard-code these events as epoch labels as follows:

event_codes <- c(1:80)
epoch_labels <- ifelse(event_codes <= 40, "face", "car")

Construct Epochs

Now, knowing event codes, we can “cut out” our epochs around them. For the epoch data, we want to include between 100-200 ms before the stimulus onset as a baseline period.

dat_epo <- epoch_data(
  dat_downs,
  event_codes,
  time_lim = c(-0.2, 0.8),
  epoch_labels = epoch_labels
)

  • X-axis: Time relative to stimulus onset

Baseline Correction

Trials will differ in their overall amplitude, i.e. due to drifts and slow artifacts. This can hide more subtle differences between conditions. The solution to this is to subtract the average activity during the pre-stimulus baseline:

dat_basl <- rm_baseline(dat_epo, c(-0.2, 0.0))
Baseline: -0.2 - 0s
erp_image(dat_basl, electrode = "PO4", smoothing = 1)

We can confirm that the average voltage during the baseline window is actually zero given an epoch and channel:

# Extract baseline time points (baseline meaning before onset, thus t < 0.0) at 
# epoch 42
inds <- which(dat_basl$timings$epoch == 42 & dat_basl$timings$time < 0.0)

mean(dat_basl$signals$FP1[inds]) # close enough to 0
[1] 5.04796e-16

Now, we can save the baseline-corrected epochs.

epo_file <- here(deriv_dir, "sub-001_task-N170_desc-epoched_eeg.rds")
saveRDS(dat_basl, epo_file)

Removing Artifacts

Independent Component Analysis

With the baseline-corrected epoch data, we can run Independent Component Analysis (ICA) to separate our EEG recordings into a number of additive sub-components. The seminar decides to separate into the 15 most important components:

n_components <- 15
ica <- run_ICA(dat_epo, method = "fastica", pca = n_components)
Reducing data to 15 dimensions using PCA.
Running fastica (ica).

With this, we can plot scalp distributions of the extracted ICA components. In particular, eye-blink and vertical eye movement components will have a very strong signal at the forehead (Comp001``Comp001), and vertical eye movement components will have opposite polarities left-frontal vs. right-frontal (maybe Comp008 and/or Comp009).

topoplot(
  ica,
  component = 1:n_components,
  limits = c(-20, 20),
  chan_marker = "none",
  scaling=0.4
)

We can also automatically detect “bad” components based on their correlation with the electrooculogram (EOG), the part that measures eye-movement signals. We set a threshold of 0.6:

heog <- c("HEOG_left", "HEOG_right")
veog <- c("FP2", "VEOG_lower")
bad_components <- ar_eogcor(ica, dat_epo, heog, veog, threshold = 0.6)
Components with high EOG correlation: Comp001 Comp006

[1] "Comp001" "Comp006"

Weirdly, in the seminar, it ends up being components 001 and 009 that are outliers, but here we see we get components 001 and 006 are the outliers. I chalk this up to the potential differences that may have come from us using different R package sources for the data we use.

Regardless, with this, we can remove the “bad” ICA components from the actual (epoched) data:

dat_icacorr <- apply_ica(dat_epo, ica, comps = bad_components)

The seminar provides useful helper functions to compare the uncorrected and corrected epochs visually:

extract_epoch <- function(epochs, epoch_no, electrode) {
  epoch_ixs <- epochs$timings$epoch == epoch_no
  data.frame(
    time = unique(epochs$timings$time),
    amplitude = epochs$signals[epoch_ixs, electrode][[1]]
  )
}

compare_epochs <- function(uncorr_epochs,
                           corr_epochs,
                           epoch_no,
                           electrode) {
  require(ggplot2)
  n_samples <- length(unique(uncorr_epochs$timings$time))
  epochs <- list(uncorr_epochs, corr_epochs) |>
    lapply(extract_epoch, epoch_no, electrode) |>
    do.call(what = "rbind")
  epochs$type <- rep(c("uncorrected", "corrected"), each = n_samples) |>
    factor(levels = c("uncorrected", "corrected"))
  ggplot(epochs, aes(x = time, y = amplitude, color = type)) +
    geom_line() +
    labs(x = "Time (s)", y = "Amplitude (µV)", color = NULL) +
    ggtitle(paste0("Epoch #", epoch_no, ", channel ", electrode)) +
    theme_minimal()
}

compare_epochs(dat_epo, dat_icacorr, epoch_no = 103, electrode = "FP1")

Artifact Rejection

ICA may not be able to correct all eye movements or other artifacts. Additionally, we want to reject all epochs where at least one channel exceeds an absolute voltage thresheld, like ±100 µV.

dat_rej <- ar_thresh(dat_icacorr, threshold = c(100, -100), reject = TRUE)
1175 (0.09%) samples above 100 uV threshold.
546 (0.04%) samples below -100 uV threshold.
18 epochs contain samples above threshold.
Removing 18 epochs.

Thresholds in practice should be chosen carefully, as rejecting many epochs reduces statistical power. More sophisticated thresholding approaches exist, e.g. via a moving window. Save artifact-corrected epochs for later:

corr_file <- here(deriv_dir, "sub-001_task-N170_desc-corrected_eeg.rds")
saveRDS(dat_rej, corr_file)

Selecting Region of Interest

We can’t just measure a single EEG electrode. For one thing, single measurements are noisy and spatially imprecise. Thus, averaging across nearby electrodes boosts our signal-to-noise ratio. For another, their measurements are not well-defined without relationships to other electrodes. Altogether, this leads to us defining the region of interest (ROI), “the set of electrodes where we expect our ERP component of interest to be maximal.”

Now, we know from prior N170 research that the face-sensitive N170 is strongest over bilateral posterior-occipitotemporal scalp, so we’ll summarize the EEG from the six electrodes covering that region:

Left Hemisphere Right Hemisphere
P7 P8
P9 P10
PO7 PO8

In particular, we have

  • P7, P8 = left/right parietal
  • P9, P10 = farther lateral/inferior left/right posterior sites
  • PO7, PO8 = left/right parieto-occipital

With this, we create a new “virtual” channel, a column in the data frame, containing the average signal in the ROI:

roi <- c("P7", "P8", "P9", "P10", "PO7", "PO8")
dat_frame$roi <- rowMeans(dat_frame[roi])

Select Time Window

ERP components unfold on the time scale of 10 ms to multiples 100s of ms. Here, we want to select the time window for where we expect our component to be — in our case, around 170 ms for the N170.

tmin <- 0.15
tmax <- 0.2

dat_frame <- subset(dat_frame, time >= tmin & time < tmax)

Averaging across this time window gets us one value, the mean ERP amplitude, per trial:

dat_trials <- aggregate(
  roi ~ epoch + event_type + epoch_labels,
  dat_frame,
  mean
)
names(dat_trials) <- c("epoch", "stimulus", "condition", "amplitude")
